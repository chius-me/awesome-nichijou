## 彩蛋与考据

《日常》埋了海量隐藏细节，以下是社区发掘的部分彩蛋：

- 每集标题卡都是一幅未改编入动画的漫画章节插图。
- 第 5 话：美绪「沉船」场景参考了库尔特·冯内古特的小说《泰坦的海妖》（书出现在画面地板上）。
- 轻音少女客串：呆唯的吉他在背景画面中一闪而过。
- 「神社事件」段落以逐帧级作画闻名，堪称烧光动画预算的名场面。

> 💡 在 YouTube / Reddit / B 站搜索 `nichijou easter egg` 或 `日常 彩蛋` 可找到更多社区整理合集。
