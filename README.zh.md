## 参与贡献

欢迎提交 Pull Request。为了让列表更容易长期维护，请遵守这些原则：

- 优先添加官方页面、稳定数据库条目和公开粉丝项目。
- 如果存在《日常》专属页面，尽量不要只链接到站点首页。
- 不添加盗版资源、私人网盘镜像或访问方式不清晰的资源。
- 避免写入容易过期的信息，例如实时评分、访问量、库存状态。
- 每个条目都需要一句简短说明，解释它为什么有用。

提交前也可以参考 [awesome list 贡献指南](https://github.com/sindresorhus/awesome/blob/main/contributing.md)。
