# Contributing to Awesome Nichijou

Thank you for helping keep **Awesome Nichijou** accurate, comprehensive, and useful for the community!

## Curation Standards

Every pull request should follow these principles:

1. **Verified & Accurate** - Visit the URL yourself before adding it. Confirm the destination matches the title and description (no wrong IDs, soft-404s, or redirects to unrelated homepages).
2. **Work-Specific Links** - Link directly to the *Nichijou*-specific page whenever one exists (e.g., a store's work category or a specific essay) rather than a generic homepage or broad channel.
3. **Legal & Publicly Accessible** - Never add piracy sites, unauthorized full uploads, or private cloud-drive mirrors.
4. **Timeless Descriptions** - Write one concise sentence explaining *why* the resource is useful. Avoid volatile claims like current ratings, view counts, or temporary stock status.
5. **Markdown Link Hygiene** - Percent-encode parentheses inside URLs (`%28` / `%29`) so Markdown renderers and automated link checkers never truncate them.
6. **Bilingual Parity** - Update both [`README.md`](README.md) (English) and [`README.zh.md`](README.zh.md) (Simplified Chinese) in the same pull request.

## Pull Request Checklist

- [ ] Entry is placed in the most relevant section and follows existing formatting (`- [Title](URL) - Concise description.`).
- [ ] Link has been checked live and uses HTTPS when supported.
- [ ] No duplicate entries exist elsewhere in the list.
- [ ] Both `README.md` and `README.zh.md` are updated together.
- [ ] Reviewed the general [awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/contributing.md).
